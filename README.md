# 📖 말씀암송 — 온누리교회 일대일 제자양육 암송구절 앱

스마트폰 홈 화면에 설치해서 쓰는 **성경암송 앱**입니다.
온누리교회 일대일 제자양육 **암송성구 32구절**(성경전서 개역한글판)을 고르면,
**검정 바탕에 흰 글자**로 화면 전체에 말씀이 나타나고 **노래 가사처럼 한 줄씩** 천천히 흘러갑니다.

| 기능 | 설명 |
|---|---|
| **정지 모드** | 구절 전체를 한 화면에 크게 표시 (화면에 맞게 글자 크기 자동 조절) |
| **가사 모드** | "장절 → 본문 한 줄씩 → 장절" 순서. 지금 줄은 진하게, 지난 줄은 흐리게 |
| **속도 조절** | 아주 느리게(0.5배) ~ 아주 빠르게(2배), 7단계 |
| **외워보기 모드** | 각 낱말의 첫 글자만 보여 주고, 줄을 누르면 정답 표시 (암송 점검용) |
| **진도 관리** | 구절마다 "외웠어요 ★" 표시 → 목록 위에 "외운 구절 n / 32" |
| **찾기** | 번호(1~32)·성경 이름·단어 검색, 단원(Ⅰ~Ⅳ) 바로가기 |
| 기타 | 이전 줄/다음 줄 직접 넘기기, 끝나면 멈춤·반복·다음 구절, 소리로 듣기, 글자 크기, 좌우로 밀어 구절 넘기기, 인터넷 없이 실행 |

📄 설계 내용: [docs/01_앱_설계구상서.md](docs/01_앱_설계구상서.md)

## 🚀 처음 한 번만: 앱을 인터넷에 공개하기 (GitHub Pages, 무료)

앱 파일을 인터넷 주소로 열 수 있게 만드는 과정입니다. **컴퓨터에서 하는 편이 쉽습니다.**

1. 이 저장소 페이지 위쪽의 **⚙️ Settings**(설정)를 누릅니다.
2. 왼쪽 메뉴에서 **Pages**를 누릅니다.
3. **Build and deployment → Source**를 **Deploy from a branch**로 둡니다.
4. **Branch**에서 앱 파일이 있는 브랜치(`main`, 또는 아직 합치지 않았다면 `claude/bible-verse-memorization-app-nhl48y`)를 고르고, 폴더는 **/(root)**, 그리고 **Save**를 누릅니다.
5. 1~2분 기다린 뒤 새로고침하면 위쪽에 앱 주소가 나타납니다:
   **`https://76wooki-afk.github.io/Scripture-Memory-Verses/`**

> 💡 **브랜치(branch)란?** 원본(`main`)을 건드리지 않고 작업하는 "사본 작업 공간"입니다. 작업이 끝나면 Pull Request로 `main`에 합칩니다.

## 📲 스마트폰에 설치하기

### 아이폰 (Safari)
1. Safari에서 위 앱 주소를 엽니다. *(크롬 말고 Safari로 여세요)*
2. 아래쪽 **공유 버튼(□↑)**을 누릅니다.
3. **"홈 화면에 추가"** → **추가**를 누릅니다.
4. 홈 화면에 생긴 📖 **말씀암송** 아이콘을 누르면 앱처럼 실행됩니다.

### 안드로이드 (삼성 인터넷 / 크롬)
1. 크롬에서 앱 주소를 엽니다.
2. 오른쪽 위 **⋮** 메뉴 → **"홈 화면에 추가"** 또는 **"앱 설치"**를 누릅니다.
3. 홈 화면의 📖 **말씀암송** 아이콘으로 실행합니다.

> 한 번 열고 나면 **인터넷이 없어도** 실행됩니다.

## 🙌 사용법

1. 목록에서 구절을 누르면 전체 화면으로 열립니다. 처음에는 **가사 모드**로 시작합니다.
   - "23번 외워 오세요" → 검색창에 `23` 입력, 또는 위쪽 `Ⅳ` 버튼으로 단원 이동
2. **화면을 한 번 누르면** 조작 버튼이 나타나고, 몇 초 뒤 저절로 사라집니다.
   - 위쪽: `목록` / `외웠어요 ☆` / `설정 ⚙`
   - `정지 | 가사 | 외워보기` — 보기 방식 바꾸기
   - `느리게 ━●━ 빠르게` — 한 줄씩 나오는 빠르기
   - `이전 구절 · 이전 줄 · ▶ · 다음 줄 · 다음 구절`
3. **설정 ⚙**: 글자 크기, 끝나면(멈춤/반복/다음 구절), 소리로 듣기, 전체 화면, 구절 편집
4. 화면을 **왼쪽·오른쪽으로 밀면** 다음·이전 구절로 넘어갑니다.

## ✏️ 구절을 고치는 방법 (모든 사람에게 적용)

구절 내용은 **`js/verses.js` 파일 하나**에 모두 들어 있습니다.

1. GitHub에서 `js/verses.js` 파일을 엽니다.
2. 오른쪽 위 **✏️ 연필 아이콘**을 누릅니다.
3. `ref`(성경 위치)와 `text`(본문)를 고칩니다. 줄을 나눌 곳에는 ` / `를 넣습니다.
   ```js
   { no: 13, section: "Ⅳ. 성장－그리스도인의 기본생활", lesson: "1과. 구원의 확신", ref: "요한일서 5:13",
     text: "내가 하나님의 아들의 이름을 믿는 / 너희에게 이것을 쓴 것은 / ..." },
   ```
   두 절 이상이면 절이 시작하는 곳에 `[6]`처럼 절 번호를 넣습니다.
4. **`sw.js` 파일의 `const VERSION = "v2";`를 `"v3"`처럼 숫자를 하나 올립니다.**
   (휴대폰이 새 내용을 받아오게 하는 신호입니다)
5. **Commit changes**(변경 저장)를 누르면 1~2분 뒤 앱에 반영됩니다.
