## 0. Executive Summary

> **Head Message**
> 앱의 핵심(전체 화면 말씀, 가사 모드)은 10명 모두 "좋다"고 평가했습니다. 그러나 **찾기·조작·진도관리 3개 구간에서 이탈 요인 12건**이 발견됐습니다. 이 중 **P1·P2 10건은 v1.2에서 수정을 끝냈고**, 남은 2건은 다음 단계 과제로 넘깁니다.

| 구분 | 내용 |
|---|---|
| **핵심 발견 ①** | **조작이 어렵다**: 아이콘만 있는 버튼 8개와 "1x" 같은 표기 때문에 60~70대와 새가족이 기능을 찾지 못함 |
| **핵심 발견 ②** | **찾기가 느리다**: 32구절 목록이 화면 6.7장 길이인데 번호와 단원 바로가기가 없음 ("23번 외워 오세요" 상황에 대응하지 못함) |
| **핵심 발견 ③** | **암송 습관과 맞지 않는다**: 성경 위치(장절)가 끝에만 나오고, 줄을 직접 넘기는 기능·진도 표시·연속 재생이 없음 |

| # | 실행 과제 (v1.2 반영) | 결과 |
|---|---|---|
| 1 | 모든 조작 버튼에 한글 이름 표시, 속도를 "보통 (1배)"처럼 말로 표시 | ✅ |
| 2 | 구절 번호(1~32), 단원 바로가기(Ⅰ~Ⅳ), 번호 검색 추가 | ✅ |
| 3 | 가사 모드를 "장절 → 본문 → 장절" 순서로 변경, 이전 줄·다음 줄 버튼 추가 | ✅ |
| 4 | "외웠어요" 표시와 진도 막대(외운 구절 n/32) 추가 | ✅ |
| 5 | 끝난 뒤 동작 선택(멈춤/반복/다음 구절)과 소리로 듣기 추가 | ✅ |

## 1. 테스트 설계

### 1-1. 방법
| 항목 | 내용 |
|---|---|
| 대상 | 가상 사용자 10명. 실제 교인이 아니라 **대표 사용자 유형을 설계한 페르소나**입니다 |
| 방식 | 각자의 기기 크기·설정·사용 상황을 **실제 브라우저 자동화로 재현**해 앱을 조작하고, 측정값을 근거로 후기를 작성 |
| 기기 | Galaxy, iPhone SE·13, Pixel, iPad 화면 크기 |
| 판정 기준 | 버튼 크기 44px 이상(Apple·Google 권장), 글자 대비 3:1 이상(WCAG), 1분 안에 목표 구절 열기 |

> ⚠️ 후기는 측정 결과를 바탕으로 쓴 **가상 후기**입니다. 실제 교인 3~5명에게 1주일 동안 써 보게 하는 실사용 검증을 권장합니다(§6).
