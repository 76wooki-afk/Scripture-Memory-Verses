# 📲 말씀암송 앱 — 스마트폰 설치 가이드 (처음 하시는 분용)

> 이 앱은 **앱스토어(플레이스토어)에서 받는 앱이 아닙니다.**
> 인터넷 주소를 휴대폰에서 연 다음, **"홈 화면에 추가"** 버튼 한 번으로 설치합니다.
> 설치하면 다른 앱처럼 홈 화면에 아이콘이 생기고, 그 뒤로는 인터넷이 없어도 열립니다.

## 전체 흐름

| 단계 | 누가 | 어디서 | 걸리는 시간 |
|---|---|---|---|
| **1단계** 앱을 인터넷에 공개하기 | 관리자 1명 (처음 **딱 한 번**) | 컴퓨터 | 5분 |
| **2단계** 앱 주소를 휴대폰으로 보내기 | 설치할 사람 | 휴대폰 | 1분 |
| **3단계** 휴대폰에 설치하기 | 설치할 사람 | 휴대폰 | 2분 |
| **4단계** 잘 설치됐는지 확인하기 | 설치할 사람 | 휴대폰 | 1분 |

> 교인들은 **2단계부터** 하시면 됩니다. 1단계는 관리자가 한 번만 해 두면 끝입니다.

---

## 1단계. 앱을 인터넷에 공개하기 (관리자 · 처음 한 번만)

지금 앱 파일은 GitHub(깃허브)라는 **인터넷 저장소**에 올라가 있습니다.
여기서 **"웹사이트로 공개" 스위치(GitHub Pages)** 를 켜면, 누구나 열 수 있는 앱 주소가 생깁니다.
GitHub 화면은 영어로 나오므로 **눌러야 할 영어 단어**를 그대로 적었습니다.

| 순서 | 할 일 | 화면에서 찾을 글자 |
|---|---|---|
| 1 | 컴퓨터에서 인터넷 창(크롬 등)을 열고 **github.com** 에 들어가 로그인합니다 | `Sign in` |
| 2 | 주소창에 아래 주소를 입력하고 엔터를 누릅니다<br>`https://github.com/76wooki-afk/Scripture-Memory-Verses` | — |
| 3 | 화면 위쪽 메뉴 줄의 맨 오른쪽 **톱니바퀴 ⚙ Settings**를 누릅니다<br>(창이 좁으면 `···` 안에 숨어 있습니다) | `Settings` |
| 4 | 왼쪽 메뉴를 아래로 내려 **Pages**를 누릅니다<br>(`Code and automation` 묶음 안에 있습니다) | `Pages` |
| 5 | **Build and deployment → Source** 칸이 `Deploy from a branch`인지 확인합니다 | `Deploy from a branch` |
| 6 | 그 아래 **Branch** 칸의 `None` 버튼을 누르고, 목록에서<br>`claude/bible-verse-memorization-app-nhl48y` 를 고릅니다 | `None` |
| 7 | 바로 옆 폴더 칸은 `/ (root)` 그대로 두고 **Save**를 누릅니다 | `Save` |
| 8 | **2~3분** 기다린 뒤 페이지를 새로고침(F5)합니다 | — |
| 9 | 위쪽에 **"Your site is live at …"** 이라는 문구가 나오면 성공입니다.<br>옆의 **Visit site**를 눌러 앱이 열리는지 확인합니다 | `Your site is live` |

✅ **이렇게 되면 성공:** 검정 화면에 "말씀암송"과 구절 목록이 보입니다.

**앱 주소 (이 주소를 교인들에게 나눠 주시면 됩니다)**
```
https://76wooki-afk.github.io/Scripture-Memory-Verses/
```

> 💡 **Branch(브랜치)가 뭔가요?** 원본을 건드리지 않고 작업하는 "작업용 사본"입니다.
> 나중에 작업본을 원본(`main`)에 합치면, 6번에서 고른 칸을 `main`으로 바꿔 주면 됩니다.

## 2단계. 앱 주소를 휴대폰으로 보내기

셋 중 **편한 방법 하나**만 고르세요.

| 방법 | 이렇게 하세요 |
|---|---|
| **① QR 코드 (가장 쉬움)** | 휴대폰 **카메라 앱**을 켜고 아래 QR 코드를 비춥니다 → 화면에 노란 글씨(주소)가 뜨면 누릅니다 |
| **② 카카오톡** | 관리자가 보낸 주소를 누릅니다. 또는 컴퓨터에서 주소를 복사해 카톡 **"나와의 채팅"** 에 붙여 넣고, 휴대폰에서 누릅니다 |
| **③ 직접 입력** | 인터넷 앱 주소창에 `76wooki-afk.github.io/Scripture-Memory-Verses` 를 그대로 입력합니다 (대·소문자 그대로) |

<img src="images/app-qr.png" alt="말씀암송 앱 주소 QR 코드" width="260">

> ⚠️ **카카오톡에서 주소를 누르면** 카톡 안의 작은 인터넷 창에서 열립니다. 그 창에서는 설치가 되지 않습니다.
> 화면 구석의 **점 세 개(⋮ 또는 ⋯)** 를 누르고 **"다른 브라우저로 열기"** (아이폰은 **"Safari로 열기"**)를 고르세요.

## 3단계. 휴대폰에 설치하기

> 먼저 내 휴대폰이 무엇인지 확인하세요. 뒷면에 🍎 사과 모양이 있으면 **아이폰**, 없으면 대부분 **안드로이드(갤럭시 등)** 입니다.

### 🍎 아이폰

> **반드시 Safari(사파리)** 로 여세요. 파란 나침반 모양 아이콘입니다. (크롬·네이버 앱에서는 설치가 잘 안 됩니다)

| 순서 | 할 일 |
|---|---|
| 1 | **Safari**에서 앱 주소를 엽니다. 검정 화면에 "말씀암송"이 보이면 됩니다 |
| 2 | **공유 버튼**을 누릅니다. 네모 위로 화살표가 나온 모양(**□↑**)입니다.<br>· 화면 **아래 가운데**에 있습니다<br>· 안 보이면 주소창 옆이나 오른쪽 아래의 **`⋯`** 를 먼저 누르면 나옵니다 |
| 3 | 아래에서 올라온 메뉴를 **위로 밀어 올려** **"홈 화면에 추가"** 를 찾아 누릅니다 (＋ 네모 모양 아이콘) |
| 4 | 이름이 **"말씀암송"** 으로 되어 있는지 봅니다. "웹 앱으로 열기" 스위치가 보이면 **켜 둡니다** |
| 5 | 오른쪽 위 **"추가"** 를 누릅니다 |
| 6 | 홈 화면에 **검정 바탕의 책 아이콘 "말씀암송"** 이 생겼습니다 🎉 |

### 🤖 안드로이드 (갤럭시 등) — 크롬 사용

> 크롬은 빨강·노랑·초록 동그라미 아이콘입니다.

| 순서 | 할 일 |
|---|---|
| 1 | **크롬**에서 앱 주소를 엽니다 |
| 2 | 오른쪽 위 **점 세 개(⋮)** 를 누릅니다 |
| 3 | **"홈 화면에 추가"** 또는 **"앱 설치"** 를 누릅니다 |
| 4 | 작은 창이 뜨면 **"설치"** 를 누릅니다 ("바로가기 만들기"와 "설치"가 둘 다 보이면 **"설치"**) |
| 5 | 홈 화면(또는 앱 목록)에 **"말씀암송"** 아이콘이 생겼습니다 🎉 |

### 🤖 안드로이드 — 삼성 인터넷 사용

> 보라색 행성 모양 아이콘입니다.

| 순서 | 할 일 |
|---|---|
| 1 | **삼성 인터넷**에서 앱 주소를 엽니다 |
| 2 | 화면 아래 오른쪽 **줄 세 개(≡)** 를 누릅니다 |
| 3 | **"현재 페이지 추가"** → **"홈 화면"** 을 누릅니다 |
| 4 | **"추가"** 를 누르면 홈 화면에 아이콘이 생깁니다 🎉 |

## 4단계. 잘 설치됐는지 확인하기

| 확인할 것 | 정상 모습 |
|---|---|
| ① 홈 화면 아이콘 | 검정 바탕에 펼친 책과 금색 십자가, 이름 "말씀암송" |
| ② 아이콘을 눌렀을 때 | **주소창 없이** 화면 전체가 앱으로 열림 |
| ③ 구절 목록 | 1번 갈라디아서 2:20부터 32번 고린도전서 3:9까지 |
| ④ 인터넷 없이 열기 | 한 번 열어 본 뒤 **비행기 모드**를 켜고 다시 열어도 열림 |

> 맨 처음에는 **인터넷이 연결된 상태에서 한 번** 열어야 합니다. 이때 앱이 휴대폰에 저장됩니다.

---

## 🔄 앱이 새로 바뀌었을 때 (업데이트)

앱스토어처럼 따로 "업데이트" 버튼을 누를 필요가 없습니다.

1. 인터넷이 연결된 상태에서 앱을 엽니다.
2. 앱을 **완전히 닫았다가**(최근 앱 목록에서 위로 밀어 닫기) 다시 엽니다.
3. 그래도 그대로면 한 번 더 닫았다가 엽니다.

---

## ❓ 이럴 땐 이렇게

| 증상 | 해결 |
|---|---|
| 주소를 열었더니 **"404"** 또는 **"There isn't a GitHub Pages site here"** | 1단계를 아직 안 했거나, 공개 후 몇 분이 안 지났습니다. 5분 뒤 다시 열어 보세요. 주소 오타(대·소문자)도 확인하세요 |
| **"홈 화면에 추가"** 메뉴가 없어요 | 카카오톡·네이버 앱 안에서 열린 경우입니다. **"다른 브라우저로 열기"** 를 누르세요. 아이폰은 꼭 **Safari** 로 여세요 |
| 아이콘을 누르면 **주소창이 보여요** | 아이폰은 4번에서 "웹 앱으로 열기"를 켜고 다시 추가하세요. 큰 문제는 아니며 사용에는 지장이 없습니다 |
| **"소리로 듣기"** 를 켰는데 소리가 안 나요 | 아이폰 옆면의 **무음 스위치**와 볼륨을 확인하세요 |
| 외운 구절 표시(★)가 **사라졌어요** | 인터넷 앱의 "방문 기록·사이트 데이터 삭제"를 하면 지워집니다. 앱을 지웠다 다시 설치해도 지워질 수 있습니다 |
| 앱을 **지우고 싶어요** | 홈 화면 아이콘을 **길게 누름** → "앱 제거"(아이폰) / "삭제"(안드로이드) |
