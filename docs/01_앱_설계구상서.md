## 0. Executive Summary (1 Page 보고)

> **Head Message**
> 암송구절이 교재·카드에 흩어져 있어 언제든 꺼내 보기 어렵다 → **스마트폰 한 번 터치로 "전체 화면 말씀 + 가사처럼 한 줄씩 흐르는 암송 모드"를 제공하는 설치형 웹앱(PWA)** 으로 해결한다.

| 구분 | 내용 |
|---|---|
| **핵심 전략 ①** | **설치 장벽 제거** — 앱스토어 심사·개발자 등록비 없이, 인터넷 주소 하나로 아이폰/안드로이드 모두 "홈 화면 앱"으로 설치 (PWA) |
| **핵심 전략 ②** | **암송 몰입 경험** — 화면 전체를 말씀으로 채우고, 노래 가사처럼 한 줄씩 등장 (속도 조절 7단계) |
| **핵심 전략 ③** | **초보자 유지보수** — 코드는 파일 6개, 구절 데이터는 1개 파일(또는 앱 안 "편집" 버튼)로만 관리 |

| # | 실행 과제 | 산출물 | 상태 |
|---|---|---|---|
| 1 | GitHub 저장소 생성 | `Scripture-Memory-Verses` | ✅ 완료 |
| 2 | 설계구상서 작성 | 본 문서 | ✅ 완료 |
| 3 | 앱 MVP 개발 (목록·전체화면·가사모드·속도조절) | `index.html` 외 | ✅ 완료 |
| 4 | 인터넷 공개 (GitHub Pages) → 스마트폰 설치 | 앱 주소(URL) | ⏳ 사용자 진행 (README 안내) |
| 5 | 암송구절 원문 대조 검수 (교재 기준) | 검수 완료 표시 | ⏳ 사용자 진행 |

## 1. 왜 이 앱인가? (Problem → Solution)

### 1-1. 3C 분석

| 축 | 사실 (Fact) | 시사점 (Implication) |
|---|---|---|
| **Customer (동반자·양육자)** | 매 만남마다 1~2절 암송, 총 16주 과정. 카드·교재를 늘 들고 다니기 어려움 | 항상 갖고 있는 **스마트폰**이 최적의 암송 도구 |
| **Competitor (기존 대안)** | 성경 앱(검색 중심, 암송 기능 약함) / 네비게이토 60구절 앱(구절 구성이 다름) / 종이 카드 | 일대일 교재 **전용 구절 + 몰입형 표시**를 함께 주는 대안은 없음 |
| **Company (우리 역량)** | 개발 경험 없음, 예산 0원, 1인 관리 | **설치·서버·비용이 없는 구조**(PWA + GitHub Pages)가 유일한 현실해 |

### 1-2. 기술 방식 비교 (Weighted Matrix)

| 평가 기준 (가중치) | ① PWA 웹앱 | ② 네이티브 앱 (Android/iOS) | ③ 노코드 앱빌더 |
|---|---|---|---|
| 초보자 난이도 (35%) | **5** — HTML 파일만 수정 | 1 — Android Studio/Xcode 필요 | 4 |
| 비용 (25%) | **5** — 0원 | 2 — 구글 $25, 애플 연 $99 | 2 — 월 구독료 |
| 아이폰·안드로이드 동시 지원 (20%) | **5** | 2 — 각각 개발 | 4 |
| 기능 구현 자유도 (20%) | 4 | 5 | 2 |
| **가중 합계 (5점 만점)** | **4.80** ✅ | 2.20 | 3.10 |

> **결론: PWA(Progressive Web App) 방식 채택.**
> PWA = "웹사이트이지만 홈 화면에 아이콘으로 설치되고, 인터넷이 없어도 열리는 앱". 사용자 입장에서는 일반 앱과 거의 동일하게 보입니다.

## 2. 사용자 시나리오 (User Journey)

```
[홈 화면 아이콘 터치]
        ↓
[① 구절 목록 화면]  만남(과)별로 정리된 22개 구절 카드
        ↓ 구절 터치
[② 전체 화면 말씀]  ─┬─ 정지 모드: 구절 전체가 한 화면에
                      └─ 가사 모드: 한 줄씩 천천히 등장 (속도 조절)
        ↓ 화면 터치 → 조작 버튼 표시/숨김
[이전·다음 구절 / 재생·일시정지 / 속도 / 글자 크기 / 화면 밝기 테마]
```

## 3. 기능 정의 (MECE: 화면 기준)

| 화면 | 기능 | 우선순위 | 설명 |
|---|---|---|---|
| **① 목록** | 만남별 구절 목록 | P1 (필수) | 과 번호·주제·성경 위치 표시 |
| | 검색 | P2 | 성경 이름·주제로 찾기 |
| | 구절 편집 | P2 | 교재와 다른 구절을 앱 안에서 직접 수정 (휴대폰에 저장) |
| **② 말씀 표시** | 전체 화면 표시 | P1 | 화면 가득, 큰 글씨, 가운데 정렬 |
| | **정지 모드** | P1 | 구절 전체를 한 번에 표시 |
| | **가사 모드** | P1 | 한 줄씩 페이드인, 현재 줄 강조·지난 줄 흐리게 |
| | **속도 조절** | P1 | 0.5배 ~ 2배 (7단계), 한 줄당 1.5초 ~ 8초 |
| | 반복 재생 | P2 | 마지막 줄 후 처음부터 자동 반복 |
| | 가리기 모드 | P2 | 글자를 가려 스스로 외워보기 (암송 점검) |
| | 글자 크기 조절 | P1 | 어르신도 볼 수 있도록 크게 |
| | 다크/라이트 테마 | P2 | 밤에는 눈부심 방지 |
| | 화면 꺼짐 방지 | P2 | 재생 중 화면이 자동으로 꺼지지 않게 |
| **③ 공통** | 오프라인 동작 | P1 | 한 번 열면 인터넷 없이도 실행 |
| | 마지막 설정 기억 | P2 | 속도·글자 크기·테마 자동 저장 |

## 5. 기술 구조 (초보자용 설명)

| 파일 | 역할 | 비유 |
|---|---|---|
| `index.html` | 화면의 뼈대 | 집의 골조 |
| `css/style.css` | 색·글씨·배치 | 인테리어 |
| `js/verses.js` | **암송구절 데이터** (가장 자주 고칠 파일) | 책장 속 책 |
| `js/app.js` | 버튼 동작·가사 재생 로직 | 전기 배선 |
| `manifest.webmanifest` | 앱 이름·아이콘 정보 (홈 화면 설치용) | 문패 |
| `sw.js` | 오프라인 저장 (서비스 워커) | 비상 창고 |

- **서버·데이터베이스 없음** → 유지비 0원, 보안 위험 최소
- **저장 위치**: 설정·편집 내용은 각 휴대폰 안(브라우저 저장소)에만 저장
- **배포**: GitHub Pages (GitHub이 무료로 웹 주소를 만들어 줌)

| 6 | 교제 | 요일 1:3 🔎 | 히 10:24-25 🔎 |
